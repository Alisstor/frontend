# Vue Frontend Starter

A Vue 3 + Vite frontend configured with Tailwind CSS and shadcn-vue components.

## Prerequisites

- Node.js 18+
- pnpm

## Install

```bash
pnpm install
cp .env.example .env
```

## Run locally

```bash
pnpm dev --host
```

## Production build

```bash
pnpm build
```

## Environment variables

- `VITE_API_URL` - backend API base URL
- `VITE_APP_NAME` - app display name

## Included stack

- Vue 3
- Vite
- Tailwind CSS
- shadcn-vue
- `@vueuse/core`
- utility libraries for class merging and icons
